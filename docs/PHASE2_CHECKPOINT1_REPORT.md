### 对 prompt 的补充
- 数据库印记 + 测试目录标记：测试库不能作为真实库打开，反之亦然。
- 显式指定的数据目录不存在时拒绝启动，避免把没插上的硬盘显示成空库。
- 同一作品的修改串行保存，响应带版本号，旧响应不覆盖新结果。
- 页面模块加载失败时不白屏（`RouteBoundary`）。

### 明确未实现
真实认证、会话、同步、平台 API、下载、解压、任务系统、安装检测、打开文件、私人空间、图片资产路由、Steam 适配器、观测表、收藏夹。连接、下载、打开在真实模式只说明后续开放。与设计的差异逐项列在 [接入方案 §10](PHASE2_INTEGRATION_PLAN.md)。

## 4. 验证方式
- **后端**：真实 SQLite 文件 + 真实应用，不 mock 数据库。

## 6. 过程中发现并修复的问题
| 问题 | 修复 |
| --- | --- |
| 首页 `totals` 字段是下划线命名，与前端不符（Pytest 发现） | 改为带别名的模型 |
| CSP 拦截字体包内嵌的 data 字体，中文字体会回退（Playwright 发现） | `font-src` 允许 `data:`；CSP 仍禁止外部来源 |
| 服务断开时打开未加载过的页面会整页白屏（Playwright 发现） | 增加 `RouteBoundary`，显示可恢复的错误 |
| 服务断开时侧栏绿色状态点仍亮（截图审查） | 随服务状态变色 |
| 切换弹层间距过紧（截图审查） | 调整间距；1280×720 下弹层内容超出一屏时可滚动 |
| 名称排序的“第 2 卷 / 第 10 卷”顺序 | 排序键内数字补零 |
| 搜索防抖未结束时前进到详情页，作品库会把查询参数写到详情页地址上（Phase 1 已存在的竞态，CI 较慢的机器上暴露） | 只在作品库路由同步地址，防抖值未变不再更新；新增回归用例 |

## 7. 已知限制
- 名称排序按 Unicode 码位，不是拼音或五十音。
- 真实模式封面只有合成样本的本地绘制和缺图占位，真实图片要到检查点 3。
- 前端类型手写，没有从 OpenAPI 生成；靠端到端用例保证一致。建议接口增多前补上。
- 请求边界没有实现 ARCHITECTURE 设想的启动 bootstrap + HttpOnly Cookie。本检查点没有敏感操作；**检查点 2 处理凭据前需重新评估**。
- 同一用户下运行的恶意程序可以读取数据库和凭据，不在保证范围内。
- 演示空间与资料库的切换设置保存在浏览器，换浏览器需要重新选。
- 没有降级迁移；恢复依靠备份。
