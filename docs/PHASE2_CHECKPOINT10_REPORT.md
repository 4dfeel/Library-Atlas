# Phase 2 · 检查点 10 报告：音声播放器与收听记录

日期：2026-10-31 · 分支 `phase-2/checkpoint-10`。

## 1. 结论
**实现完成，真实作品待人工验证。** 用自制 WAV 经真实接口、真实 Range 请求和浏览器真实 `<audio>` 元素验证过播放、跳转、接续、跨页和定时停止。夜间没有播放任何真实作品。

## 2. 做了什么
- 详情页“收听”：类型为音声的作品，从默认本地副本找音频文件，按文件夹分组、自然排序（`2` 在 `10` 前）。
- 底部播放器：全局只有一个音频元素，换页不中断。上一首、下一首、跳转、音量、静音、循环（关/列表/单曲）、随机、倍速、定时停止。
- 记录：收听位置、最后听的曲目、书签、播放列表都存数据库，重启后还在。
- 文件不可读时提示一次，不循环重试。

## 3. 规则
| 情况 | 处理 |
| --- | --- |
| 打开页面、刷新、重启 | **不自动播放**，只显示“继续收听”，点了才响 |
| 接口如何指定文件 | 副本 ID + 曲目 ID，请求里没有路径。曲目 ID 由相对路径算出，服务端列出文件后比对 |
| 符号链接、目录联接 | 不进入，不播放目录外的文件 |
| 文件变了（大小或修改时间） | 旧位置不再套用 |
| 文件被移走 | 书签和播放列表保留，书签显示“文件已不在” |
| 文件夹离线 | 显示不可用，不当成空，不删记录 |
| 隐藏、私人、隔离的作品 | 接口一律 404；从播放列表结果中去掉，恢复后回来 |
| 非普通文件类型（txt、jpg 等） | 不列出，也不能经音频接口读取 |

## 4. 格式
| 格式 | 状态 |
| --- | --- |
| WAV | 已验证（测试自制） |
| MP3、FLAC、OGG、Opus、M4A、AAC | 接口可提供，**未在真实文件上验证**。测试用的 Chromium 不含部分专利解码器，实际取决于你的浏览器；不能解码时页面会提示 |
| WMA、APE、TAK、TTA、WV、MIDI | 列出但标为无法在这里播放，可打开目录用其他播放器 |

## 6. 已知限制
- 只读默认副本。
- 时长在首次加载后才知道，不提前扫描文件头。没有读取标签和内嵌封面，曲名就是文件名。
- 音量、倍速、循环只在本次打开期间保留，不写入数据库。
- 播放列表整表保存，页面上没有调整顺序的按钮，目前只能把一部作品的曲目存成一个列表。
- 随机模式下“上一首”也是随机，不回到真正的上一首。
- 单次最多列出 20,000 个文件，超出时页面会说明。
- 同名文件移动到别的文件夹算新曲目，旧位置和书签不跟随。
