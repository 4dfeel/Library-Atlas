- 按 ID 读取与修改统一隐私过滤；私人、隐藏、待确认、不存在 ID 返回同一错误与同一页面。
- 加载骨架、读取失败重试、不可用页、图片失败回退、保存失败；Ctrl+K 与备注输入冲突处理；减少动画模式。

**偏差与理由**
- **路由**：检查点 1 没有路由方案。未新增依赖，写了约 90 行 History API 路由（`src/lib/router.ts`）。后续嵌套路由增多时可再评估路由库。
- **评分范围**：原模型无评分字段，新定义为 1–5 整星、`null` 为未评分，已写入 DESIGN §10。
- **收藏持久化**：检查点 1 收藏仅会话内保留；按本检查点要求改为与其他演示修改同存储、刷新保留，可重置。
- **背景素材**：原 `background` 字段指向 2:3 竖版封面；改为生成 24 幅 2:1 原创 SVG 背景，避免拉伸竖图。
- **存储隔离**：键为 `library-atlas.demo-edits.v1.atlas-demo-41544c41`（版本 + 数据集）。1500/5000 两种规模前 1500 条记录完全相同，因此共用一份修改；版本或数据集不符、格式错误的内容一律忽略。
- 新增 `components/app-link.tsx`、`components/feedback-state.tsx`（从 App 抽出复用）；`App.tsx` 中 Library 页面迁至 `features/library/library-page.tsx`，行为不变。

**未完成 / 不在范围**：Dashboard、完整 Private Library、真实启动/安装/Steam 同步（“启动游戏”禁用并文字说明）、后端与数据库。前端过滤只是演示隔离，**不是**未来后端访问控制。

- 复用 AppShell、Sidebar、Header、全部设计 token、字体、Button、Tooltip、Dialog、GameCover/缺图占位、状态色点、焦点环与动效规则；未改 Library 外观（仅卡片标题改为链接、整卡可点击、收藏按钮置于上层）。

- 正文：简介（≤68ch）｜标签·成就·收藏档案（细线分隔）｜唯一抬升的“我的记录”面板。4K 内容框架 2560px 居中、背景铺满；窄窗口逐级合并为单列。细则见 DESIGN §10。

## 3. Demo 数据、持久化与隐私
- 详情字段由 `lib/data/details.ts` 以独立种子按 ID 确定性生成，列表记录不变（单测验证 1500/5000 前缀一致）。24 张插画封面、程序化封面、约 9% 缺封面、20% 无背景保持不变。
- 演示修改保存在本浏览器 localStorage；读取时校验版本、数据集、ID 格式与字段范围；写入失败（配额/禁用）显示为保存失败。Playwright 每个测试使用全新浏览器上下文；Vitest 使用内存存储。
- 隐私覆盖：`list`、`getGame`、`updateGame`、`toggleFavorite`、封面与背景 URL 选择。私人 ID 存储中的伪造修改不会显示；修改接口只接受状态/评分/备注/收藏，`visibility` 等字段被拒绝。

## 7. 性能实测
环境同检查点 1 报告（Windows 11、i9-13900K、Chromium 156.0.8078.4 headless、1920×1080@1、减少动画、构建后本地预览）。方法：在 Library 页面内 `performance.now()` 起计，程序点击游戏链接，至详情标题出现后下一帧；再点击“返回游戏库”至首张卡片出现后下一帧。每种规模 6 款游戏轮换共 10 次；同时统计每次打开的封面/背景请求数。原始数据 `artifacts/checkpoint-2/performance.json`。

| 规模 | 打开详情中位 / 最大 | 返回 Library 中位 / 最大 | 每次打开图片请求 |
| --- | --- | --- | --- |
| 1500 | 31.0ms / 357.2ms | 26.7ms / 34.1ms | 0–1 |
| 5000 | 31.3ms / 70.6ms | 26.1ms / 27.3ms | 0–1 |

1500 首次最大值包含详情路由懒加载分块（约 20KB）的首次加载。5000 场景中 `demo-04000` 可打开并修改状态；1500 场景访问该 ID 显示不可用。打开详情不会批量请求封面；Library 虚拟化与挂载上限测试仍通过。这是本机强硬件上的就绪采样，不是标准 TTI，也不代表低配机器。
