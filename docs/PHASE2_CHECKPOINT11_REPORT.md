# Phase 2 · 检查点 11 报告：漫画/CG 阅读器与阅读记录

日期：2026-10-31 · 分支 `phase-2/checkpoint-11`。

## 1. 结论
**实现完成，真实作品待人工验证。** 图片文件夹、ZIP/CBZ、PDF 都能在 Atlas 内阅读，用自制文件经真实接口和浏览器真实渲染验证过，断言的是页面真实解码的尺寸和像素，不只是按钮文字。夜间没有打开任何真实作品。

## 2. 做了什么
- 详情页“阅读”：类型为图像的作品，按磁盘结构分组列出，显示进度。
- 阅读器：单页、双页、纵向；左右方向；适合页面、适合宽度、缩放；全屏；页码和跳页；书签；继续阅读；手动标记已读。
- 键盘：方向键、PageUp/PageDown、空格、Home/End、`+`/`-`、`B` 书签、`F` 全屏、Esc。焦点在输入控件上时不翻页。点击屏幕左右三分之一翻页，中间不翻。

## 3. 格式
| 格式 | 状态 |
| --- | --- |
| PNG 图片文件夹 | 已验证（测试自制） |
| JPEG、WebP、GIF、BMP | 文件头解析有测试（JPEG、GIF），**真实文件未在浏览器验证** |
| AVIF | 可提供；文件头读不到尺寸，只受文件大小限制 |
| ZIP、CBZ | 已验证（测试自制）。原地读取，不解压到磁盘；cp932 文件名已验证 |
| PDF | 已验证简单 PDF（pdf.js 本地打包）。真实日文、扫描版 PDF **未验证** |
| RAR、CBR、7z、CB7 | 列出并说明原因，先解压成文件夹后可读 |
| EPUB、MOBI、AZW3 | 列出并说明原因，不支持 |
| `.dlst` 等平台专用格式 | 列出并请用官方阅读器，不解密 |
| SVG | 不当作页面（可含脚本） |

## 4. 规则
| 情况 | 处理 |
| --- | --- |
| 分册 | 每个直接含图片的文件夹一册，每个 ZIP/PDF 一册，不混合 |
| 压缩包内多个文件夹 | 算同一册，按路径排序，标题栏显示当前章节 |
| 页面顺序 | 自然排序，`2` 在 `10` 前；重复图片不去重 |
| 双页 | 封面单独，其余 2-3、4-5 配对，最后一张落单时单独 |
| 页面身份 | ID 包含文件内容版本。换了文件就不是同一页 |
| 上次的页不在了 | 明确提示，从第一页开始，不冒充另一页 |
| 加了新页 | 位置按 ID 找回，不串页 |
| 已读 | 翻到最后一页或手动标记。打开不算，打开也不写进度 |
| 已读后回看 | 仍是已读 |
| 坏页 | 只有这一页显示占位和重试，其他页正常 |
| 损坏的压缩包或 PDF | 明确提示，其他册不受影响，记录不删 |
| 离线 | 显示不可用，不当成空 |
| 隐藏、私人、隔离的作品 | 接口一律 404 |

## 5. 安全边界
- 请求里没有路径，只有副本 ID、册 ID、页 ID。不跟随符号链接和目录联接。
- 扩展名不算数，文件头对不上就拒绝（415）。单边超过 65535、总像素超过 4 亿、文件超过 256 MB 的页拒绝，在解码之前。
- 压缩包：成员上限 5 万，总量上限 64 GB，单页 256 MB，压缩比超过 200 倍的成员拒绝，同时最多读 4 页。读取时再限一次大小，防止索引谎报。路径不安全、加密的成员不提供，数量会告诉用户。
- PDF：只画页面内容。关闭批注层，所以链接、表单、附件都不生效；不运行脚本，不用 eval；字体和字符表来自本地构建。测试用一个带打开脚本和外链的 PDF 确认没有弹窗、没有外部请求、没有 CSP 报错。

## 6. 新依赖
`pdfjs-dist@5.4.149`，精确版本，Apache-2.0，Mozilla 维护。只在打开 PDF 时加载。worker、字体、字符表都打进构建（`dist/pdfjs`）。版本选的不是最新（6.x），因为 5.4 已稳定且满足需要，升级需另外验证。

## 7. 这次顺带修的问题
- **ZIP 日文文件名误判（C5 也受影响）**：含“表”“ソ”“能”这类字符的 cp932 文件名，第二个字节恰好是反斜杠，Python 的 `zipfile` 把它改成了斜杠，导致编码判断失败，整个压缩包被当成“编码错误”。解压也走这段代码，所以修复同时覆盖 C5。
- **测试数据里没有图像和音声**：合成数据的取模规则让这两类永远不会生成，已修正。

## 9. 已知限制
- 纵向模式靠浏览器懒加载，图片尺寸事先不知道，往回翻时图片加载可能让位置轻微移动。
- 页面列表不读文件头，尺寸异常的页在打开时才发现。
- 双页配对固定“封面单独”，没有调整的开关，跨页错位时只能切单页。
- PDF 只有普通渲染：pdf.js 5 解码部分 JPEG2000、JBIG2 图片需要 WebAssembly，而当前 CSP 不允许，这类扫描版可能缺图。需要真实文件确认后再决定是否放开。
- 没有文字层，PDF 不能选中文字。
- 有密码的 PDF 提示无法打开，不提供输入框。
- 压缩包里不进入嵌套压缩包。
- 进度绑定副本：取消关联后重新关联，进度不会自动找回。
- 阅读方式和方向存在本机浏览器，不进数据库。
- 只有图像类作品显示阅读入口，游戏或其他类作品里的图片不显示。

## 补充：滚轮翻页（2026-10-31，用户要求）
单页、双页模式下滚轮翻页，向下总是下一页，与阅读方向无关。页面比窗口高时先滚动，到边缘才翻。纵向模式仍是滚动，Ctrl+滚轮留给浏览器。每次翻页后停 0.22 秒，防止一次快速滚动翻过很多页。
