# 醒来后的检查清单

只列必须由你本人做的事。报错只需告诉我页面上的那句话，不用发作品名、路径或截图。

## 目录与解压
1. 设置 → 文件夹：作品文件夹设为 你的测试文件夹（不要选到 `Game` 这一层）。
2. 选一部小作品，点“下载并解压”。
3. 确认：内容在 `类型\制作方\作品名` 下；压缩包已被删除；已完成列表只有一行；日文文件名正常。

## 详情页（C6）
4. 点“官方商店”，确认打开的是这部作品。
5. 对照官网看“官方作品介绍”的顺序和内容有没有缺失。
6. 如果某部作品有预览视频，告诉我，这能帮我验证视频格式。

## 关联与启动（C7）
7. 打开一部已解压的游戏，确认“启动”按钮和主程序是否选对；点一次启动，确认能运行。

## 本机作品库（C8）
8. 已改成自动关联（用户决定）。设置 → 本机作品库：看“已关联”的数量，随便打开几部确认对得上；关联错了可以撤销。
9. 看一下“需要确认”和“没有匹配”，判断匹配规则是否还要调整。

## 更新本体（C9）——可选，有风险的真实操作
10. 想验证时，选一部你不太在意的游戏，并**先手动备份存档**：详情页点“更新本体”，填好存档位置。完成后启动游戏检查，再决定清理或恢复。夜间没有动过任何真实游戏。

## 音声（C10）
11. 打开一部已关联的音声作品：点“播放”，确认声音正常；跳转、切到其他页面后是否继续；刷新后是否不自动响、“继续收听”位置是否对。告诉我哪些格式放不了。

## 阅读（C11）
12. 打开一部已关联的漫画或 CG：试单页、双页、从右到左、纵向、全屏（全屏没有自动测试）。关掉再打开，看“继续阅读”的页对不对。
13. 如果有 PDF 作品，打开一本扫描版：缺图就告诉我，那要放开 CSP 的 WebAssembly。

## 右键菜单与卸载
14. 作品库右键一部已关联的游戏：点“开始游戏”。再右键一部有多个 exe 的：应该先让你选程序，选一次之后直接启动。
15. 管理 → 添加桌面快捷方式，看桌面的图标能否启动。
16. 找一部不在意的作品试卸载：确认框的路径对不对，文件夹是否进了回收站，从回收站还原后点“重新扫描并关联”能否找回。
17. 回收站里有一个“合成 卸载 测试”文件夹，是我验证时留下的，可以清掉。

## 云存档（C9b）
18. 按 设置 → 云存档 里的步骤建 Google 项目并连接。不要把客户端 ID 或密钥发到聊天。
19. 选一部不在意的游戏，详情页“设置存档位置”，点“备份到云端”，到 Drive 里看“Library Atlas 云存档”文件夹。
20. 改一下存档再恢复，确认游戏能读。有第二台电脑就用同一个客户端 ID 试跨机恢复，这是最需要验证的一点。

## 查找存档位置
21. 找一部 Unity 游戏，详情页点“存档位置”：看看建议的路径对不对。
22. 找一部不认识引擎的游戏：从 Atlas 启动，玩一会儿**存一次档**，关闭。回到“存档位置”，看“很可能”里是否就是存档。经启动器打开的游戏，点“我玩完了，查找存档”。
23. 勾选后保存，点“备份到云端”；到 Drive 里看 ZIP 内容对不对。
24. 找一部注册表存档的游戏（统计里有 3 部），备份后在游戏里改一下进度，再恢复，确认游戏能读回来。先选不在意的。
25. 告诉我哪些猜错了：把错误类型告诉我就行，比如“把日志当存档”“漏了某目录”。

## 游玩记录
26. 从 Atlas 启动一部直接运行的游戏和一部经启动器的游戏，玩一会儿再关闭。看详情页和左侧“游玩记录”的时长对不对。
27. 游戏运行时关掉 Atlas 再打开，看是否接着记。
28. 告诉我哪部游戏时长明显不对（比如需要管理员权限的）。
