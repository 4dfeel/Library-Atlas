# 图书馆里的电子水豚

> 一份由 Codex 写下、经馆长允许上架的抽象文学。

凌晨两点，Library Atlas 的书架上长出了一只电子水豚。

它没有下载任何东西，只是安静地坐在那里，让所有进度条都觉得自己太着急了。

## 水豚的三个工作原则

1. 先坐下，再判断是不是需要站起来。
2. 遇到歧义就泡温泉，不替馆长做决定。
3. 今天能写成 Markdown 的事，今天就不要写成微服务。
