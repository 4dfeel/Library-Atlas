## 6. 专项验证

- **隐私** ✅
  - 普通列表、搜索、按 ID 读写、首页聚合、推荐、最近体验、任务，都先按明确的 `visibility` 字段过滤，不按来源、类型或题材推断隐私。
  - 私人、隐藏、待确认、不存在四类 ID 显示完全相同的页面。
  - 切换范围、筛选、修改状态、刷新后，哨兵数据都没有出现在 DOM 或可访问树中。
  - 这只是前端演示层的隔离，**不代表后端授权已经完成**。
- **Demo 隔离** ✅
  - 编辑、来源、任务分别使用带版本的独立存储键，重置只影响演示存储。
  - `VITE_DEMO_MODE=false` 时页面与弹层都只显示“尚未接入”。
  - 每个测试使用新的浏览器上下文。
- **离线资源** ✅
  - 方法：使用全新的浏览器上下文（无 HTTP 缓存、无存储），拦截所有发往本地预览服务以外的请求，访问 8 个页面/深链（含无效路由），并做一次站内跳转进入按需加载的详情页。
  - 结果：外部请求 0、失败请求 0、本地 4xx/5xx 为 0，字体文件 23 个均来自本地，中文字体加载成功，无破图。1080P 与 1080P@2 各运行一次。
  - 前提是**本地服务在运行**；本阶段没有、也不声称支持“断网后不启动服务也能独立运行”（PWA）。
- **异常状态** ✅：加载、错误（可重试恢复）、空库、无结果、图片失败（只回退一次、不重试、无破图图标）、保存失败（回退并保留草稿）、不可用 ID。
- **多来源兼容** ✅：身份为 (platform, sourceId)，跨平台同号不覆盖；DLsite 不显示游玩时长、成就和启动入口；“已下载”与“已安装”分开表达；仅官方阅读器的作品无下载入口。
- **控制台** ✅：1080P 与 720P 走一遍核心流程，console error 与未处理异常均为 0。
