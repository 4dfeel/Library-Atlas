# Library Atlas 详细教程

全程不用敲命令，照着做就行。需要 Windows 11，大约 10 分钟。

## 安装

### 1. 安装 Python

1. 下载 [Python 3.14](https://www.python.org/ftp/python/3.14.3/python-3.14.3-amd64.exe)，双击打开。
2. 点 **Install Now**，等它装完。

### 2. 安装 Node.js

1. 下载 [Node.js 22](https://nodejs.org/dist/v22.22.1/node-v22.22.1-x64.msi)，双击打开。
2. 一路点 **Next**，最后点 **Install**。

### 3. 安装 7-Zip（可选）

只有 RAR 和 7z 格式的作品需要它，不装也能解压 ZIP。到 [7-Zip 下载页](https://www.7-zip.org/download.html) 下载 25.01 或更新的 64 位版本，双击安装。

### 4. 下载 Library Atlas

1. 打开 [项目主页](https://github.com/4dfeel/Library-Atlas)，点绿色的 **Code** 按钮，再点 **Download ZIP**。
2. 右键下载的 ZIP，选“全部解压缩”，放到你想放的位置，比如 `D:\Library-Atlas`。路径里有中文或空格都没关系。

如果页面打不开，说明仓库目前是私有的，需要先登录有访问权限的 GitHub 账号。

### 5. 运行安装

打开解压出来的文件夹，**双击 `install.cmd`**。

窗口里可能闪过很多英文，不用管。看到“安装完成”后按任意键关闭。

如果 Windows 弹出“已保护你的电脑”，点 **更多信息**，再点 **仍要运行**。

### 6. 打开

**双击 `start.cmd`**，浏览器会自动打开 Library Atlas。

使用期间不要关闭那个黑色窗口，用完直接关掉它就行。以后每次使用，都只需要双击 `start.cmd`。想更方便的话，可以右键 `start.cmd`，选“发送到 → 桌面快捷方式”。

## 第一次使用

打开后作品库是空的，这是正常的。

1. **登录 DLsite**：点左下角的“设置”，在“账号”里登录。只有勾选“记住账号和密码”，才会保存密码。
2. **同步作品**：登录后点“同步”，你买过的作品会出现在作品库。
3. **选择文件夹**：在“设置 → 文件夹”选择作品的下载和解压位置。
4. **关联已有作品**：用 DLsiteNest 下载过的作品，Atlas 会自动查找各盘的 `DLsiteNest\Library` 并关联，只记录位置，不改动文件。放在其他位置的，到“设置 → 本机作品库”手动添加。

### 云存档（可选）

想把存档备份到自己的 Google Drive，到“设置 → 云存档”，按页面上的步骤操作。授权只在 Google 官方页面进行，只上传你确认过的存档，不上传游戏本体。

## 更新到新版本

1. 关掉黑色窗口。
2. 按上面第 4 步下载新的 ZIP，解压后替换旧文件夹。
3. 双击 `install.cmd`，装好后双击 `start.cmd`。

你的资料不在这个文件夹里，替换不会丢失。资料库结构有变化时，程序会先自动备份再升级。

## 卸载

1. 关掉黑色窗口，删除 Library Atlas 文件夹。
2. 不再需要资料的话，按 `Win + R`，输入 `%LOCALAPPDATA%\LibraryAtlas`，回车，删除打开的文件夹。这会清除评分、备注和游玩记录，无法恢复。
3. 打开“控制面板 → 凭据管理器 → Windows 凭据”，删除以 `LibraryAtlas/` 开头的条目。

作品文件放在你自己选的文件夹里，卸载不会动它们。

## 遇到问题

**`install.cmd` 说还没有安装 Python 或 Node.js**
按提示的地址安装。如果已经装了，重启一次电脑再试。Python 要装 3.14 版本。

**`install.cmd` 显示“安装没有成功”**
多半是网络问题，重新双击一次。还是不行，就把最后几行提示发给帮你的人，注意遮住里面的用户名和路径。

**`start.cmd` 说还没有安装**
先双击 `install.cmd`，等它显示“安装完成”。

**页面显示“本地服务未连接”**
黑色窗口被关掉了，重新双击 `start.cmd`。你的资料不受影响。

**提示端口 8765 已被占用**
别的程序占用了这个端口，关掉它，或者重启电脑后再试。

**RAR 或 7z 作品无法解压**
安装或升级 7-Zip 到 25.01 以上。Atlas 不会使用旧版本，因为旧版本有把文件写到目标文件夹外面的安全漏洞。

## 资料保存在哪里

| 内容 | 位置 |
| --- | --- |
| 资料库、封面缓存、自动备份 | `%LOCALAPPDATA%\LibraryAtlas\profiles\default` |
| 登录会话、记住的密码、Google 授权 | Windows 凭据管理器，名称以 `LibraryAtlas/` 开头 |
| 作品文件 | 你在“设置 → 文件夹”里选择的位置 |

## 安全提示

- 不要用端口转发或内网穿透把 Atlas 暴露到网上，它没有登录这一步。
- 游戏是以你的身份运行的程序，恶意程序能读到你的 Windows 凭据。来源不明的作品不要直接运行。
- 不要把账号、密码、Cookie 或 Google 客户端密钥发给任何人。
