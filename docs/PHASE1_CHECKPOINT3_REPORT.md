## 2. 视觉决策与复用
- 复用 AppShell、侧栏、顶栏、设计 token、Button/Dialog/Tooltip、GameCover 与缺图占位、详情页的背景与遮罩（`HeroBackdrop`、`hero-scrim`）、DEMO 与平台徽标、状态色点、细线分隔的关键数据样式。没有新增颜色 token。

- 细则见 [DESIGN §12](DESIGN.md)。

## 3. 模型、Demo 数据、隐私与存储
- **模型增量**：
  - `sourceId`：与平台组合为身份。演示中 DLsite 条目刻意复用前一个 Steam 条目的编号，单测验证不会互相覆盖。
  - `capabilities`：download / extract / officialViewerOnly，按作品而非按平台硬编码。
  - `file`：version 与 sizeBytes；大小未知为 null，不显示 0 B。
  - `installed` 文案按平台区分：Steam 为已安装/未安装，DLsite（含游戏）为已下载/未下载。下载完成不会让游戏变成“已安装”或可启动。
  - `lastPlayedAt` 定义为最近使用记录。
  - 详见 ARCHITECTURE §9.1。
- **分布（1500 件，私人/隐藏/待确认过滤后普通可见 1463）**：
  - Steam 游戏 984；DLsite 479，其中游戏 158、漫画/图像 80、视频 81、音声 81、其他 79。
  - DLsite 中：约 10% 仅限官方阅读器（不可下载）；约 8% 文件大小未知；约 1/4 已开始的作品没有使用记录。
  - 5000 件场景按相同规则生成，前 1500 条完全一致。
  - 全部为原创、全年龄、虚构制作方。未使用任何参考截图中的账号、邮箱、作品名或封面。
- **素材**：沿用 24 幅原创插画封面与 2:1 背景，其余为程序化封面（同类型作品配色错开），约 9% 明确缺封面，20% 无背景。
- **演示数据调整**（为了真实可信，未改变 ID、隐私分布或缺图比例）：
  - 使用时间改为约 60 天内按分钟分布，避免最近列表按 ID 排序并列。
  - 程序化标题的词序与类型周期错开。
  - 游玩时长改为指数分布（多数较短、少数很长）。
- **隐私**：首页所有计数、精选、最近、推荐、图表与来源计数都从“先过滤普通可见”的同一快照计算。单测验证私人哨兵不出现在任何范围；把私人条目单独喂入时结果全空。按 ID 读写沿用检查点 2 的统一过滤，`markDownloaded` 对私人或不存在的 ID 同样拒绝。
- **存储**：
  - 演示修改沿用 `library-atlas.demo-edits.v1…`，新增可选字段 `downloaded`。v1 内容保持有效，既有评分、备注、收藏不会丢失。
  - 连接状态单独存在 `library-atlas.demo-sources.v1…`，只保存粗粒度状态，不含任何凭据。
  - 任务只存在于内存：刷新会丢弃未完成任务（作品重新显示为未下载），已完成结果通过 `downloaded` 保留。
  - “重置演示修改”同时清空任务与连接状态。
- **单一状态源**：状态、评分、收藏、下载完成都写入同一演示源；完成后统一让缓存失效，首页、作品库与详情同步更新（单测与浏览器测试均有覆盖）。

## 8. 性能实测
环境同前序报告（Windows 11、i9-13900K、Chromium 156.0.8078.4 headless、1920×1080@1、减少动画、本地构建预览）。原始数据在 `artifacts/checkpoint-3/performance.json`。

方法：
- **导航**：从作品库点击侧栏“首页”，到精选区与 4 项关键数据出现后的下一帧，5 次。
- **范围切换**：点击后到页面范围标记更新且无忙碌状态后的下一帧，5 个范围轮换 10 次。

| 规模 | 导航到精选+关键数据（中位/最大） | 范围切换（中位/最大） |
| --- | --- | --- |
| 1500 | 21.9ms / 46.8ms | 29.9ms / 71.9ms |
| 5000 | 19.0ms / 27.8ms | 32.4ms / 52.4ms |

限制：
- 范围切换的计时终点是页面范围标记更新，聚合结果在同一或随后的微任务中替换。这是 UI 响应采样，不是严格的“新数字可见”时间。
- 强硬件上的结果，不代表低配机器，也不是标准 TTI。
- 首页每次只渲染可见的少量封面；作品库虚拟化不变。
