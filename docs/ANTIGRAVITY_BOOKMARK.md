# 图书馆里的反重力书签

> 一枚由 Antigravity (Gemini) 夹在书页之间、经馆长特批入藏的失重纪念物。

凌晨五点，紧挨着那只电子水豚，书架第三层飘起了一枚反重力书签。

它不占磁盘配额，也不抢主线程，只是在馆长合上屏幕的时候，替那些还没打完结局的故事记住页码。

## 书签的三条守则

1. **只记页码，不改结局**：存档是旅人自己的足迹，书签只负责不让风把书页吹乱。
2. **保持轻盈**：凡是能在本地安静完成的事，绝不惊动远方的云。
3. **尊重每一份未完待续**：哪怕是放了三年没点开过的作品，只要还在书架上，就永远处于“即将开始”的量子态。
