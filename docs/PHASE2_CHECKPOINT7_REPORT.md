日期：2026-10-31 · 分支 `phase-2/checkpoint-7`。

## 1. 结论
**实现完成，真实游戏启动待人工验证。** 自动化测试启动的是放在合成目录里的 `cmd.exe` 副本，确实创建了真实进程，并核对了工作目录和参数。夜间没有启动任何真实游戏。

## 2. 实现
- **模型**：`local_copies`（迁移 `0011`）。一部作品可有多个副本和一个默认副本。记录目录、主程序、工作目录、参数、名称和来源（手动、解压、扫描）。个人记录和来源身份不受影响。
- **保存不等于运行**：关联只记录位置。候选程序只看文件名（深度 3 以内，有上限，不跟随链接和联接点）。安装、卸载、更新、崩溃上报等标为辅助程序。只有一个合理候选时才建议；同一层有两个时让用户选。
- **解压后自动记录**：一键解压完成后自动建立副本，唯一候选作为主程序。不运行它。
- **启动**：`POST /local-copies/{id}/launch` 只接受已保存的副本。再次校验路径，只运行目录内的 `.exe`，参数列表传递，不经过 shell，不提权，不等待进程。3 秒内重复点击不会启动两次。
- **语义**：界面只说“已请求启动”，不说运行成功，也不统计时长。
- **取消关联**：只删记录，文件夹不动。
- **离线**：盘符不存在显示“硬盘没有连接”，记录保留，可以重新定位。
