## 4. 同步规则
| 项目 | 规则 |
| --- | --- |
| 触发 | 只有用户点击；登录、打开页面、服务启动都不会开始 |
| 并发 | 一次一个任务；再次点击加入正在运行的任务 |
| 写入 | 每批一个短事务，停在任何位置都只留下完整的作品，可安全重跑 |
| 幂等 | 按（来源，来源编号）更新；编号不透明，不做解析和合并 |
| 个人记录 | 同步代码写不到个人记录表：评分、备注、状态、收藏、可见性都保留，加入日期只在首次写入 |
| 缺字段 | 这次响应没给的字段保留旧值，不清空 |
| 不再列出 | 只有完整同步才标记 `not_currently_observed`，作品和记录都保留 |
| 成功时间 | 只有完整同步才更新；失败、取消、部分失败都不更新 |
| 重试 | 网络、限流、5xx 最多 3 次，尊重 Retry-After；401 立即停止并要求重新登录 |
| 结构异常 | 不是列表、声明有作品却列表为空、一批全部无法识别：停止，不写入，不说成空库 |
| 部分无法识别 | 跳过并报告，结果标记为部分完成 |
| 取消 | 批次边界生效，已写入的保留 |
| 重启 | 进行中的任务标记为中断，不自动重跑 |
| 退出或换号 | 每批写入前校验会话代次，晚到的响应不写入 |

类型只看 `work_type`，不根据标题或封面猜：
- **游戏**：ACN ADV RPG SLN STG PZL QIZ TBL TYP DNV ETC
- **漫画/图像**：MNG SCM ICG WBT VCM
- **音声**：SOU MUS
- **视频**：MOV
- **其他**：NRE PBC TOL IMT AMT ET3 及未知代码

**没有的数据不伪造**：没有游玩时长、成就、最近使用；购买日期不算使用；本机状态为未知。真实响应里还有文件类型、大小、语言等字段，留给下载检查点。

## 7. 过程中发现并修复
- 切换筛选时数量会闪“0”：现在保留上一次的数字直到新结果到达。
- 假作品编号与样本撞号暴露了测试计数错误，也验证了按编号去重确实生效。
- 重复同步的耗时最初量错（页面显示着旧结果就结束计时），已改为等待新任务结束。

## 8. 已知限制
- 接口非公开，可能随时变化；变化时同步停止并提示，不写入错误数据。
- 没有简介：接口不提供，也没有爬商店页面。
- 8 部未返回的作品没有进入作品库，只显示数量；Atlas 不知道是哪几部的资料，因为没有写入。
- 名称排序按 Unicode 码位，不是拼音或五十音。
- 第一次显示封面时要下载，之后走缓存（本次约 23 MB）。缓存没有自动清理。
- 图片缓存在本机数据目录，未加密。
- 收起状态下要向上滚动才能使用顶栏和筛选。
- “大小”栏要重新同步一次才有数值，单位假定为字节，尚未与平台比对。
- “作品形式”显示的是类型标签（同步来自 `work_type`），不是平台页面上的原文。
