## 3. 内容模型
`works.intro_json` 保存校验过的块，和短简介 `description`、个人备注分开。块类型：heading、paragraph（含安全链接）、list、table、image、video。保留页面顺序，不摘要、不翻译、不改写。解析器版本变化时重读，成功前不丢旧内容。

## 4. 安全
- 用标准库 `html.parser` 按白名单**只复制**允许的内容，不存 HTML，前端也不注入 HTML。script、style、form、svg、object、事件属性、内联样式都带不过来，有测试。
- 链接只保留 https 的 dlsite.com，其余变成纯文字。图片只接受平台图片主机，页面只拿到 Atlas 的序号地址。
- 跳转只跟随指向同一作品的平台地址，最多 4 次。页面 4 MB 上限。
- 没有介绍区的页面（验证页、新版式）报 `changed`，不当成空介绍保存。

## 5. 状态与失败
| 情况 | 行为 |
| --- | --- |
| 平台确实没有介绍 | `empty`，显示“没有提供详细介绍” |
| 第一次读取失败 | `unavailable`，不保存，下次重试 |
| 已有内容后读取失败 | 保留旧内容，提示并标 `stale` |
| 手动刷新 | 60 秒内不重复请求 |

介绍失败不影响详情其他部分。

### 真实验证发现的问题
合成测试全部通过时，真实作品却全被判为“已下架”：作品会跳转到另一分区，而代码把所有跳转都当成下架。现在只跟随指向同一作品的跳转。这说明这类结论必须有真实验证。

## 7. 已知限制
- 视频只有卡片，要去官方页面看。
- 商店页版式变化时显示“和预期不同”，需要改解析器。
- 语言固定为 `zh-cn`。作品没有中文页时显示原文，不翻译。
- 图片缓存没有自动清理。
- 长图按原比例显示，会占很长的页面，这是有意的：不裁切文字。

## 8. 运行
