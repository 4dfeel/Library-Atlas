# Library Atlas 产品需求

状态：Phase 0 评审稿；2026-10-30 用户决定扩展为多平台“作品库”（见 §8）。本文为目标与验收基线，不代表功能已实现。

## 1. 产品目标与边界
面向 Windows 11、拥有 1000–1500+ 款 Steam 游戏及 DLsite 等平台作品的个人用户，以收藏展示、快速整理和减少选择负担为核心。默认简体中文、深色主题、本地优先；断网仍可查看已有数据和整理收藏。正式运行通过浏览器访问单一 localhost 服务。

MVP 为路线图 Phase 1–5 的累计交付，不等于 Phase 1。只支持一个活动 Steam 账号；不开发交易、购买、社区聊天、云端账号系统、DRM 绕过或 Steam 文件写回。不收集 Steam 密码、Cookie、会话令牌；DLsite 仅在用户主动登录后保存会话（不保存密码，见 §8）。MVP 不是游戏安装器或精确计时器；DLsite 一键下载解压为调查后的候选功能。

## 2. 核心概念
| 概念 | 产品含义 |
| --- | --- |
| 库存 | 有来源记录的条目；已安装不等同于已拥有，缺席不等于失去所有权 |
| Atlas 隐藏 | 普通库和推荐默认排除，可在隐藏管理区恢复；不改变 Steam |
| Atlas 私人 | 普通查询、统计、搜索提示、推荐、导出均排除；仅显式进入私人空间后访问 |
| Steam 隐藏/私密 | 外部平台状态；与 Atlas 本地设置独立，读取能力待调查 |
| 私人收藏 | 收藏夹及成员关系仅在私人空间出现；加入时提示并将条目设为 Atlas 私人，移出不自动取消私人状态 |
| Backlog | 用户定义的游玩计划，不由游玩分钟数自动推断通关 |
| 待确认区 | 隐私状态未知、冲突或来源不可靠的导入条目，默认不公开展示 |

“普通页面”包括首页、作品库、公开收藏、Backlog、推荐、统计以及搜索弹层。这里的公开仅指本机普通视图，不代表对互联网分享。私人空间是防误展示边界，不提供对同一 Windows 用户或管理员的强隔离。

## 3. 功能与验收
| 模块 | MVP | 后续扩展 | 关键验收 |
| --- | --- | --- | --- |
| 作品库 | Steam 与 DLsite 合并展示；作品类型（游戏/图像/视频/音声/其他）与平台筛选、网格/紧凑列表、名称/制作方搜索、类型/标签/本机/进度状态筛选、排序、详情、批量本地操作 | 复杂保存视图、自定义封面、更多平台 | 筛选可组合、条件可清除；1500 条虚构数据；刷新后本地设置保留 |
| 多来源同步 | 官方 Web API 库存/近期游玩适配器、只读本地 Steam 安装扫描、受校验手动导入；手动启动、进度、取消、摘要、失败重试 | 定时同步、多账号、更多商店、远端双向操作 | 每字段显示来源/更新时间；部分失败不清空库存；重复同步不重复建条目 |
| 自动分类 | 确定性规则，基于可用的类型、标签、安装与游玩数据；多标签；预览、解释、手动覆盖及锁定 | 自然语言/模型分类、社区规则市场 | 缺元数据归入待分类；重跑不覆盖锁定结果；批量变更可撤销 |
| 隐藏与私人 | 本地隐藏、私人、待确认区、显式私人入口、返回即关闭；批量变更前确认 | 经验证后读取 Steam 状态；系统凭据辅助解锁 | 普通 API 和关联计数不返回私人内容；未知状态不自动放行；不承诺 Steam 回写 |
| 收藏 | 普通/私人收藏夹，增删成员、名称、说明；收藏夹删除保留游戏 | 动态收藏、嵌套、可选加密导出 | 私人集合名称、封面及数量不泄漏；公开集合自动过滤私人游戏 |
| Backlog | 未规划/想玩/在玩/搁置/已完成/放弃；优先级、备注、手动排序 | 目标提醒、日历、计划时长 | 变更立即持久化；零游玩不自动标为未完成；隐藏/私人统一过滤 |
| 推荐 | 仅已拥有且可见游戏；根据用户偏好、标签、Backlog、游玩情况本地打分；推荐理由、不感兴趣、可复现的换一批 | 本地嵌入、更多反馈信号、可选外部模型 | 冷启动说明依据不足；候选不足不补入私人游戏；无外部 AI 传输 |
| 游玩统计 | 可见游戏数、累计游玩、近期数据、类型分布、Backlog 分布、采集覆盖率 | 本地快照趋势、年度回顾、成就分析 | 标注来源、时间窗、缺失范围；未知不等于 0；不伪造每日历史/单次会话 |

MVP 类型和标签可来自手动资料；商店元数据自动补全以技术调查通过为前提，不以未公开端点作为硬依赖。商店库存不指 Steam 社区物品库存。

## 4. 关键流程
1. 首次启动：说明本地存储和隐私边界 → 选择 Demo 或真实资料 → 配置 SteamID/API Key 或本地路径 → 试连/扫描 → 导入摘要 → 待确认条目检查 → 入库。
2. 隐私确认：可靠证据证明非私密或用户明确“作为普通条目导入”才进入普通视图；可批量确认，但不能预勾选。已本地设为私人者不会被同步解除。
3. 同步：保留旧快照可读 → 按来源获取 → 校验与去重 → 事务合并 → 分来源报告成功/失败/未知与最后成功时间。取消不撤销已提交的独立批次，摘要清楚说明。
4. 整理：筛选 → 选择游戏 → 预览分类/收藏/状态变更 → 提交；危险变更确认，普通本地编辑支持撤销。
5. 选择游玩：查看推荐理由 → 查看详情 → 加入在玩；MVP 不要求启动游戏。
6. 私人空间：显式进入 → 短期会话访问 → 离开/刷新关闭 → 普通页重新查询；不把私人标题写入浏览器持久存储、URL 或系统通知。

## 5. 页面与反馈
首页展示继续整理、推荐和近期概览；游戏库为主工作区。独立页面包括收藏、Backlog、推荐、统计、同步中心、设置、隐藏管理、私人空间/待确认区以及游戏详情。核心页面必须覆盖截图，弹窗覆盖批量操作、导入预览和来源说明。

空库引导同步或 Demo；筛选无结果可清除条件；离线显示缓存时间；权限不足显示可操作解释；同步失败保留旧数据并可重试。错误不能暴露密钥或私人标题。Demo 全程显示“演示模式 · 合成数据”，不悄悄切换真实数据。

## 6. 非功能验收
- 1920×1080 CSS 视口无意外横向滚动；补测 1366×768 及 Windows 125%/150% 缩放对应视口；长中英文标题、emoji、缺图、损坏图统一处理。
- 1500 条合成数据使用虚拟化及延迟图片加载；性能预算及测量方式见 DESIGN。键盘可完成搜索、筛选、打开详情和返回。
- 私人/隐藏筛选由服务端统一实现，测试不仅检查 DOM，也检查普通 API、图片访问、聚合和导出。
- 断网可浏览和整理；重复同步幂等；迁移与恢复可验证；用户文件及 Steam 文件不受写入影响。
- 不上传库存或用户行为；联网同步及封面获取需明确告知，私人条目不自动联网请求。导出、备份与清理行为展示范围。

## 7. 不确定项与完成判断
Steam 私密/隐藏读取、所有权完整度、游玩字段可得性、本地格式和封面来源均见 ARCHITECTURE 风险表。接口受限时展示真实限制，采用手动导入/本地标记降级；不得通过抓取登录会话绕过权限。MVP 完成必须通过 ROADMAP 的 Phase 5 门禁。

## 8. 多平台作品库与 DLsite（2026-10-30 用户决定）
用户目标：用 Atlas 替代 DLsite Nest 的日常浏览、整理和打开；Nest 可继续承担下载，直到 Atlas 的下载能力经调查确认。

- **用词**：主区称“作品库”，计量“部作品”；状态为 未开始/进行中/已完成/搁置。游戏显示“已安装”，其他作品显示“已下载”。
- **作品类型**：游戏 / 图像 / 视频 / 音声 / 其他，独立于玩法分类；Steam 条目均为游戏。作品库顶部按类型切换并显示数量，另可按平台筛选。
- **平台差异如实呈现**：DLsite 不提供可用游玩时长与成就时显示制作方、发售日等实际资料，不伪造 0 或进度。
- **账号连接**：DLsite 通过官方登录页登录一次；Atlas 只保存会话（Windows 凭据管理器），**不保存密码**；可随时断开。会话失效由 DLsite 决定，失效时提示重新登录并保留已有库存。只读：不购买、不改账号设置。手动或低频刷新，失败不刷屏重试。
- **库存来源优先级（待调查）**：①只读 Nest 本地缓存；②官方登录页 + 会话读取购买列表；③本地目录扫描按作品编号（RJ/VJ 等）关联；④手动导入编号。能力、条款与稳定性在 Phase 2 调查后确定，未经验证不宣称支持。
- **打开作品**：游戏启动用户确认过的可执行文件；图像/视频/音声用系统默认程序或打开所在文件夹；仅限官方阅读器的作品显示“在 DLsite 阅读器中打开”，不绕过授权。
- **隐私默认**：DLsite 新同步条目先进入待确认区，确认前封面与标题不出现在普通页面；可设置按作品类型默认归入私人空间。
- **一键下载解压（候选，未承诺）**：在会话可用且条款允许的前提下，下载用户已购作品的分卷、校验、合并并解压到用户指定目录后自动入库；需许可证认证的作品交给官方工具，不绕过。解压防路径穿越与压缩炸弹；RAR/分卷需要的外部组件属依赖决策，需用户确认后引入。
