## 实测性能
环境：Windows 11 Pro 10.0.26300、Intel Core i9-13900K（24 核/32 线程）、约 64GB RAM、Node 22.22.1、npm 10.9.4、Playwright 1.64.1 / Chromium 156.0.8078.4。浏览器为本机 headless，1920×1080 CSS px、DPR 1、减少动画、无 CPU 降速；明显强于设计参考硬件，不能据此保证低配机器表现。

| 规模 | 导航至首卡可见且字体就绪 | 搜索输入至结果 p95 | 自动化端到端搜索 p95 | 10 秒滚动平均 FPS | 首屏/滚动后挂载卡片 | >50ms 长任务 |
| --- | --- | --- | --- | --- | --- | --- |
| 1500 | 281.9ms | 168.3ms | 220.7ms | 60.20 | 28 / 42 | 0 |
| 5000 | 139.4ms | 165.3ms | 221.1ms | 60.07 | 28 / 42 | 0 |

方法：使用构建后的本地静态预览。导航计时为 `performance.now()`，等待首卡和字体；这是保守就绪采样，并非标准 TTI 指标。每规模交替搜索两个唯一名称 20 次；浏览器在 input 事件起计，MutationObserver 发现正确唯一结果后下一帧结束，包含 140ms 防抖。自动化端到端数值另含 Playwright 传输、操作和轮询，未把它冒充纯渲染时间。滚动使用 requestAnimationFrame 每帧移动 18px、持续 10 秒计帧；PerformanceObserver 记录长任务。两种规模首屏各请求 24 个不同本地封面 URL，没有请求数千张封面。第二规模复用浏览器缓存，非严格冷启动比较。原始 20 次采样保存在 `artifacts/checkpoint-1/performance.json`。

## 截图与真实视觉检查
证据目录：`artifacts/checkpoint-1/screenshots/<档位>/`。七档分别为 1920×1080@1、2560×1440@1、3840×2160@1、2560×1440@1.5、1920×1080@2、1280×720@1、1440×900@1。每档保存网格、列表、无结果、缺图、长标题、加载、错误、空库，共 56 张。所有资料为合成数据，未进入私人页面；截图与 trace 不提交 Git，CI 单独保留短期 artifact。

已实际打开审查 1080P/2K/4K 网格、1280×720 网格、1080P 列表、2K 长标题、4K 缺图、DPR 1.5 网格、DPR 2 列表、无结果及加载/错误/空库的代表截图。自动化检查覆盖全部档位的页面宽度、卡片比例、长标题、图文边界和控件交互；其他截图不冒称逐张精细人工审核。

实际发现与修复：
1. 首版卡片元数据和筛选辅助字偏小 → 提高时长、状态、筛选与页脚字号，复看后层级更清楚。
2. 1280×720 首屏介绍区过高，封面标题落到滚动区域下方 → 添加低高度紧凑布局，首屏可同时看到封面、标题和时长。
3. 设置弹窗 Esc 关闭后焦点未返回按钮 → 捕获并恢复触发控件，组件与浏览器回归通过。
4. 列数变化导致卡片重挂载、键盘焦点丢失 → 按游戏 ID/控件类型恢复，不抢占工具栏焦点；缩放与滚动锚点回归通过。
5. 缺图截图最初可能在防抖完成前保存 → 等待结果名称匹配查询后再截图，避免把旧结果当成验收证据。
6. 4K 骨架与真实网格列数不一致 → 共用容器测量和网格尺寸算法，加载时不再跳变成另一种卡片密度。

没有为了凑问题数编造修复。未单独保留初始截图副本；以上“修复前”描述来自当时实际打开的截图与可复现测试，最终图片均为修复后的证据。

## 主要决策与限制
- 继续沿用 Phase 0 配色、字栈、间距和封面比例。非对称页头提供收藏氛围；主区由封面承担色彩，4K 增加到约 14 列而不无限放大组件。
- 当前全部图片为矢量，天然适应 DPR；无需伪造位图 srcset。未来真实位图仍应按规范提供 sizes/srcset。字体由 npm 包本地构建，OFL 许可证随构建提供。
- Vite 提示单个 JS chunk 约 570KB（gzip 约 184KB）超过默认 500KB 提示线；构建成功、当前性能通过，后续页面加入时应按路由拆包，未隐藏该提示。
- 本机禁止执行 PowerShell 脚本，`.ps1` 启动检查未执行；可用 `.cmd` 入口或 README 的 `npm.cmd` 指令，避免要求用户降低系统策略。
- Demo 的前端过滤仅保护演示展示，不是未来真实账号的服务端安全实现；没有数据库、密钥或真实用户数据。收藏仅在会话保留。真实 Windows 缩放、低配硬件和用户视觉审查仍待完成。
