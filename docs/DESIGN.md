# Library Atlas 设计系统

状态：Phase 0 已审核；Phase 1 检查点 1 视觉实现待用户确认。设计目标是有收藏感、安静而有层次的深色游戏画廊。封面承担视觉主角，数据辅助选择；避免密集报表、满屏高饱和渐变和大面积玻璃模糊。首版中文界面，统一使用“私人空间”“待确认区”“游玩时长”等术语。

## 1. 色彩与材质
以下为语义 token 初稿，Phase 1 使用实际组件验证 WCAG AA 对比度后固化；禁止页面自行硬编码近似颜色。

| Token | 色值 | 用途 |
| --- | --- | --- |
| background | #0B0E14 | 全局背景 |
| sidebar | #10141D | 导航 |
| surface | #151B26 | 卡片/面板 |
| surface-raised | #1D2634 | 弹窗/悬停 |
| border | #303D50 | 控件边界；装饰分隔可用低透明度 |
| text-primary | #F2F5FA | 正文/标题 |
| text-secondary | #B6C2D2 | 次要说明 |
| text-muted | #91A0B5 | 辅助信息；禁用于不可辨认的小字 |
| accent | #8CB4FF | 主操作/选中/链接 |
| accent-foreground | #0B1428 | 主按钮文字 |
| success | #6AD7AC | 成功 |
| warning | #F0C36B | 待确认/陈旧数据 |
| danger | #FF9C9C | 错误/危险 |
| private | #CEB3FF | 私人入口与状态 |

选中使用 accent 12% 底色 + 边界/勾选图形，不单靠颜色。私人与隐藏同时使用文字及图标。图片上文字必须有不透明度足够的独立底板或渐变遮罩。焦点为 2px accent 外环、2px offset。正文对比至少 4.5:1，大字和必要图形至少 3:1；装饰边框不承担唯一交互识别。

## 2. 字体与排版
- 字体栈：`"Segoe UI Variable", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`；无需联网加载字体。数字使用 tabular-nums。
- 页面标题 28/36、区块标题 20/28、卡片标题 15/22、正文 14/22、辅助 12/18；字重 400/500/600，避免细字。数字指标 32/40。
- 页面标题最多两行；卡片标题固定两行 line-clamp，保留完整 accessible name；悬停及键盘焦点可见完整名称提示，详情展示全文。列表单行 ellipsis；名称容器 min-width:0；连续长字符串使用 overflow-wrap:anywhere。
- 日期显示本地格式，来源时间带时区说明；时长统一以分钟存储、小时展示，未知显示“暂无数据”。

## 3. 空间、布局与信息层级
- 间距采用 4px 基线：4/8/12/16/20/24/32/40/48/64。面板圆角 12px、卡片 12px、控件 8px、弹窗 16px。阴影只用于浮层：0 16px 48px rgba(0,0,0,.35)。
- 1920×1080：导航侧栏 232px，顶栏 64px；内容边距 32px；页标题/摘要下方 24px 进入工具栏与内容。内容区宽度约 1624px，常规网格 7 列，列间距 20px，单卡约 215px。
- 网格按可用宽度自适应，最小卡宽 176px；1366 宽通常 5 列。小于 1280 时侧栏折叠至 72px，内容边距 24px；更窄允许 1–4 列及工具栏换行。不得以 overflow-x:hidden 掩盖溢出。
- 只有主内容容器纵向滚动，导航稳定；弹窗可独立滚动且焦点受控。筛选栏吸顶但不遮住焦点。虚拟网格以滚动容器实际宽度计算列数与行高。
- 游戏库：标题/可见数量 → 搜索与主要筛选 → 已选条件 → 网格。详情使用 16:9 横幅与两栏资料；统计使用少量图表及简短解释，不能只靠颜色传达值。

## 4. 游戏卡片与图片
- 标准封面区域固定 **2:3**，CSS aspect-ratio；object-fit:cover、居中裁切，不拉伸。横向详情横幅 16:9，列表缩略图 2:3；不把横幅变形成竖封面。
- 卡片下方固定两行标题及一行辅助信息，整卡行高一致；卡片内边距 12px。最多两个状态徽章，其余收进详情。
- 缺图/解码错误使用同一 2:3 本地 SVG 占位：低对比 Atlas 图案 + 游戏首字/短名，背景使用 surface。占位资源无私人文字与远程请求。
- 悬停边界提亮并上移 2px，不改布局尺寸；选中用复选框和边界；键盘焦点可见；打开详情为主操作，收藏与更多操作为独立按钮，禁止嵌套按钮。
- 图片预留尺寸防 CLS；仅加载可见项与有限预取，失败不无限重试。私人封面使用受保护本地路由，不通过通用静态目录暴露。

## 5. 共用组件与交互
shadcn/ui 组件经统一 token 适配后复用：Button、Input、Select、Dialog、Dropdown、Tooltip、Tabs、Checkbox、Toast。图标统一 lucide 风格，16/20/24px，图标按钮有 accessible label。

标准控件高 40px，紧凑控件 32px，触控目标不小于 32×32；搜索宽度 320–480px，可收缩。主操作每区通常一个；破坏性动作放次级菜单并说明影响。批量选择显示固定操作条和选中数量，筛选改变时明确是否清除选中，默认清除以防误操作。

收藏、Backlog 使用同一游戏卡组件；统计、同步、设置沿用同一标题、面板、边界、反馈组件。私人空间持续显示锁图标和“私人空间”，返回普通页面立即关闭授权并清理前端私人缓存。待确认区不在普通导航角标透露数量。

## 6. 动画
Motion 用于轻量状态切换：hover 120ms、弹层 180ms、页内淡入 200ms，缓动 cubic-bezier(.2,.8,.2,1)。只动画 opacity/transform；不用整页飞入或大列表逐项入场。1500 项虚拟网格禁止退出动画阻塞回收。

遵循 prefers-reduced-motion：移除位移、缩放和 shimmer，保留必要即时状态变化。加载进度不能由无限动画代替文字信息。

## 7. 反馈状态
| 场景 | 表现与恢复操作 |
| --- | --- |
| 初次加载 | 与最终卡片等尺寸骨架 + “正在读取本地游戏库”，延迟超过 10 秒说明原因并可重试 |
| 同步中 | 顶部非阻塞进度条、来源/已处理数量、取消；不伪造未知百分比 |
| 空库 | 精简插图、说明、配置同步/导入/Demo 入口 |
| 筛选无结果 | 保留条件、提供清除筛选 |
| 离线/缓存陈旧 | 横幅和最后成功时间，保留可用内容 |
| 局部错误 | 面板内错误、重试；其他内容继续使用 |
| 全局错误 | 清晰原因、重试/诊断入口，诊断脱敏 |
| 保存成功 | 小型 toast；关键状态在页面持续可见，读屏通过 aria-live 宣告 |
| 删除/隐私变更 | 明确对象范围，确认/取消；能撤销的本地操作提供撤销 |
| Demo | 顶栏持续琥珀色“演示模式 · 合成数据”，设置中说明隔离位置 |

## 8. UI 验收与证据
- Playwright 固定 1920×1080、统一浏览器版本/系统字体/缩放/DPR、冻结时间与合成种子、禁用动画；每个 PRODUCT 核心页面留正常态截图，另覆盖空/错/加载、缺图、超长中英文标题。私人页面仅用无敏感文字的合成占位，默认截图流程不进入私人空间。
- 普通页面植入私人哨兵数据，断言 DOM、可访问树、普通响应、计数与截图均不出现；真实库存禁止用于截图基线或 trace。
- 检查 document.scrollWidth <= clientWidth，图片自然比例与容器比例，无布局跳动；补测 1366×768 与 125%/150% Windows 缩放。
- 性能基线：Windows 11、4 核 CPU、16GB RAM、SSD、固定 Chromium；记录 CPU 型号/浏览器版本/commit。1500 条带长标题/缺图数据，在本地图片缓存条件下，库页可交互 ≤2 秒，搜索/筛选触发至可见结果 p95 ≤200ms（20 次），连续滚动 10 秒平均 ≥55fps，操作期间无 >200ms 主线程长任务。冷启动网络耗时单独报告，不混入本地预算。
- 虚拟化仅保留可见行及约 2 屏 overscan，DOM 卡片数不随全库线性增长；键盘焦点不因回收丢失。性能证据使用 trace/测量结果，不以截图代替。
- 对比度、键盘导航、焦点返回、Esc 关闭和读屏标签人工复核；首次基线由用户评审后保留，禁止为掩盖退化直接更新快照。

## 9. 检查点 1 响应式实现补充
- 布局依据 CSS 视口而非显示器物理像素；Library 可用宽度由 ResizeObserver 测量。卡片目标宽 176–240 CSS px、列间距 20px，最大宽度 240px；按测量结果计算虚拟行/列，4K 下继续增加列数而不放大字体或强制居中窄栏。不足一列时可缩小至容器宽度避免溢出。
- 侧栏 232px，收起为 72px；1280px 及以下自动收起。手动收起与窗口缩放都重新测量列数，保留首个可见条目所在行作为滚动锚点；不是强行保持失去语义的旧 scrollTop 数值。
- Library 顶部使用非对称编辑式标题和单幅原创新世界插画，清晰区分页面介绍和收藏浏览区；不创建 Dashboard 模块。虚拟列表复用封面、状态、收藏按钮，信息列在窄宽下有序收缩。
- 主字体继续采用 Segoe UI/微软雅黑系统风格，并本地打包 OFL 授权的 Noto Sans SC Variable 作为中文可移植回退。不使用 Google Fonts/CDN。字号使用限定 token；不随 vw 无限增长。
- 当前封面与图标均 SVG，无位图 DPR 插值问题。24 幅插画具有不同场景构图；程序化封面明确写 ATLAS STUDIES；缺失封面显示“封面待收录”，不会把程序化插画当作缺图。
- 检查点 1 验收：1920×1080@1、2560×1440@1、3840×2160@1、2560×1440@1.5、1920×1080@2、1280×720@1、1440×900@1。每档保存网格、列表、无结果、缺图、长标题截图并执行布局断言。仅为 Playwright CSS 视口/DPR 近似，不代表实际 Windows 系统缩放已验证。
- 首页和详情等未实现入口禁用并说明后续开放；收藏操作在 Demo 会话内有效。正式视觉基线仍须用户评审，不因自动化通过而替代人工确认。
