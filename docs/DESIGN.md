# Library Atlas 设计系统

状态：Phase 0 已审核；Phase 1 检查点 1 视觉实现待用户确认。设计目标是有收藏感、安静而有层次的深色游戏画廊。封面承担视觉主角，数据辅助选择；避免密集报表、满屏高饱和渐变和大面积玻璃模糊。首版中文界面，统一使用“私人空间”“待确认区”“游玩时长”等术语。

## 1. 色彩与材质
以下为语义 token 初稿，Phase 1 使用实际组件验证 WCAG AA 对比度后固化；禁止页面自行硬编码近似颜色。

| Token | 色值 | 用途 |
| --- | --- | --- |
| background | #0B0E14 | 全局背景 |
| sidebar | #10141D | 导航 |
| surface | #151B26 | 卡片/面板 |
| surface-raised | #1D2634 | 弹窗/悬停 |
| border | #303D50 | 控件边界；装饰分隔可用低透明度 |
| text-primary | #F2F5FA | 正文/标题 |
| text-secondary | #B6C2D2 | 次要说明 |
| text-muted | #91A0B5 | 辅助信息；禁用于不可辨认的小字 |
| accent | #8CB4FF | 主操作/选中/链接 |
| accent-foreground | #0B1428 | 主按钮文字 |
| success | #6AD7AC | 成功 |
| warning | #F0C36B | 待确认/陈旧数据 |
| danger | #FF9C9C | 错误/危险 |
| private | #CEB3FF | 私人入口与状态 |

选中使用 accent 12% 底色 + 边界/勾选图形，不单靠颜色。私人与隐藏同时使用文字及图标。图片上文字必须有不透明度足够的独立底板或渐变遮罩。焦点为 2px accent 外环、2px offset。正文对比至少 4.5:1，大字和必要图形至少 3:1；装饰边框不承担唯一交互识别。

## 2. 字体与排版
- 字体栈：`"Segoe UI Variable", "Segoe UI", "Noto Sans SC Variable", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif`；拉丁字符用 Windows 系统字体，中文由本地打包的 Noto Sans SC Variable 渲染（见 §9）；无需联网加载字体。数字使用 tabular-nums。
- 页面标题 28/36、区块标题 20/28、卡片标题 15/22、正文 14/22、辅助 12/18；字重 400/500/600，避免细字。数字指标 32/40。
- 页面标题最多两行；卡片标题固定两行 line-clamp，保留完整 accessible name；悬停及键盘焦点可见完整名称提示，详情展示全文。列表单行 ellipsis；名称容器 min-width:0；连续长字符串使用 overflow-wrap:anywhere。
- 日期显示本地格式，来源时间带时区说明；时长统一以分钟存储、小时展示，未知显示“暂无数据”。

## 3. 空间、布局与信息层级
- 间距采用 4px 基线：4/8/12/16/20/24/32/40/48/64。面板圆角 12px、卡片 12px、控件 8px、弹窗 16px。阴影只用于浮层：0 16px 48px rgba(0,0,0,.35)。
- 1920×1080：导航侧栏 232px，顶栏 64px；内容边距 32px；页标题/摘要下方 24px 进入工具栏与内容。内容区宽度约 1624px，常规网格 7 列，列间距 20px，单卡约 215px。
- 网格按可用宽度自适应，最小卡宽 176px；1366 宽通常 5 列。小于 1280 时侧栏折叠至 72px，内容边距 24px；更窄允许 1–4 列及工具栏换行。不得以 overflow-x:hidden 掩盖溢出。
- 只有主内容容器纵向滚动，导航稳定；弹窗可独立滚动且焦点受控。筛选栏吸顶但不遮住焦点。虚拟网格以滚动容器实际宽度计算列数与行高。
- 游戏库：标题/可见数量 → 搜索与主要筛选 → 已选条件 → 网格。详情使用 16:9 横幅与两栏资料；统计使用少量图表及简短解释，不能只靠颜色传达值。

## 4. 游戏卡片与图片
- 标准封面区域固定 **2:3**，CSS aspect-ratio；object-fit:cover、居中裁切，不拉伸。横向详情横幅 16:9，列表缩略图 2:3；不把横幅变形成竖封面。
- 卡片下方固定两行标题及一行辅助信息，整卡行高一致；卡片内边距 12px。最多两个状态徽章，其余收进详情。
- 缺图/解码错误使用同一 2:3 本地 SVG 占位：低对比 Atlas 图案 + 游戏首字/短名，背景使用 surface。占位资源无私人文字与远程请求。
- 悬停边界提亮并上移 2px，不改布局尺寸；选中用复选框和边界；键盘焦点可见；打开详情为主操作，收藏与更多操作为独立按钮，禁止嵌套按钮。
- 图片预留尺寸防 CLS；仅加载可见项与有限预取，失败不无限重试。私人封面使用受保护本地路由，不通过通用静态目录暴露。

## 5. 共用组件与交互
shadcn/ui 组件经统一 token 适配后复用：Button、Input、Select、Dialog、Dropdown、Tooltip、Tabs、Checkbox、Toast。图标统一 lucide 风格，16/20/24px，图标按钮有 accessible label。

标准控件高 40px，紧凑控件 32px，触控目标不小于 32×32；搜索宽度 320–480px，可收缩。主操作每区通常一个；破坏性动作放次级菜单并说明影响。批量选择显示固定操作条和选中数量，筛选改变时明确是否清除选中，默认清除以防误操作。

收藏、Backlog 使用同一游戏卡组件；统计、同步、设置沿用同一标题、面板、边界、反馈组件。私人空间持续显示锁图标和“私人空间”，返回普通页面立即关闭授权并清理前端私人缓存。待确认区不在普通导航角标透露数量。

## 6. 动画
Motion 用于轻量状态切换：hover 120ms、弹层 180ms、页内淡入 200ms，缓动 cubic-bezier(.2,.8,.2,1)。只动画 opacity/transform；不用整页飞入或大列表逐项入场。1500 项虚拟网格禁止退出动画阻塞回收。

遵循 prefers-reduced-motion：移除位移、缩放和 shimmer，保留必要即时状态变化。加载进度不能由无限动画代替文字信息。

## 8. UI 验收与证据
- Playwright 固定 1920×1080、统一浏览器版本/系统字体/缩放/DPR、冻结时间与合成种子、禁用动画；每个 PRODUCT 核心页面留正常态截图，另覆盖空/错/加载、缺图、超长中英文标题。私人页面仅用无敏感文字的合成占位，默认截图流程不进入私人空间。
- 普通页面植入私人哨兵数据，断言 DOM、可访问树、普通响应、计数与截图均不出现；真实库存禁止用于截图基线或 trace。
- 检查 document.scrollWidth <= clientWidth，图片自然比例与容器比例，无布局跳动；补测 1366×768 与 125%/150% Windows 缩放。
- 性能基线：Windows 11、4 核 CPU、16GB RAM、SSD、固定 Chromium；记录 CPU 型号/浏览器版本/commit。1500 条带长标题/缺图数据，在本地图片缓存条件下，库页可交互 ≤2 秒，搜索/筛选触发至可见结果 p95 ≤200ms（20 次），连续滚动 10 秒平均 ≥55fps，操作期间无 >200ms 主线程长任务。冷启动网络耗时单独报告，不混入本地预算。
- 虚拟化仅保留可见行及约 2 屏 overscan，DOM 卡片数不随全库线性增长；键盘焦点不因回收丢失。性能证据使用 trace/测量结果，不以截图代替。
- 对比度、键盘导航、焦点返回、Esc 关闭和读屏标签人工复核；首次基线由用户评审后保留，禁止为掩盖退化直接更新快照。

## 9. 检查点 1 响应式实现补充
- 布局依据 CSS 视口而非显示器物理像素；Library 可用宽度由 ResizeObserver 测量。卡片目标宽 176–240 CSS px、列间距 20px，最大宽度 240px；按测量结果计算虚拟行/列，4K 下继续增加列数而不放大字体或强制居中窄栏。不足一列时可缩小至容器宽度避免溢出。
- 侧栏 232px，收起为 72px；1280px 及以下自动收起。手动收起与窗口缩放都重新测量列数，保留首个可见条目所在行作为滚动锚点；不是强行保持失去语义的旧 scrollTop 数值。
- Library 顶部使用非对称编辑式标题和单幅原创新世界插画，清晰区分页面介绍和收藏浏览区；不创建 Dashboard 模块。虚拟列表复用封面、状态、收藏按钮，信息列在窄宽下有序收缩。
- 主字体继续采用 Segoe UI/微软雅黑系统风格，并本地打包 OFL 授权的 Noto Sans SC Variable 作为中文可移植回退。不使用 Google Fonts/CDN。字号使用限定 token；不随 vw 无限增长。
- 当前封面与图标均 SVG，无位图 DPR 插值问题。24 幅插画具有不同场景构图；程序化封面明确写 ATLAS STUDIES；缺失封面显示“封面待收录”，不会把程序化插画当作缺图。
- 检查点 1 验收：1920×1080@1、2560×1440@1、3840×2160@1、2560×1440@1.5、1920×1080@2、1280×720@1、1440×900@1。每档保存网格、列表、无结果、缺图、长标题截图并执行布局断言。仅为 Playwright CSS 视口/DPR 近似，不代表实际 Windows 系统缩放已验证。
- 首页和详情等未实现入口禁用并说明后续开放；收藏操作在 Demo 会话内有效。正式视觉基线仍须用户评审，不因自动化通过而替代人工确认。

## 10. 检查点 2：游戏详情页
- 路由 `/library/<稳定 ID>`（5000 场景附 `?size=5000`）。私人、隐藏、待确认、不存在及格式错误 ID 使用同一个“找不到这款游戏”页面，文案、结构与焦点完全相同，不透露记录是否存在。
- **标题规则**：详情标题完整显示、允许换行，不沿用卡片两行截断。字号随内容区宽度（cqi）在上下限内变化：常规 34–60px；超过 28 字 28–46px；超过 60 字 24–38px；行宽上限 22/28/34em，`overflow-wrap:anywhere` 处理无空格长串，`text-wrap:balance` 平衡多行。
- **顶部展示区**：全宽，最小高度 `clamp(440px, 58vh, 1180px)`，低高度窗口 420px。宽屏背景 `object-fit:cover`、焦点 `center 42%`；遮罩为左→右（#0B0E14 94%→8%）、底部融入背景、顶部轻遮三层渐变，保证标题、徽标与按钮对比度。内容与 Library 页头同一左对齐边距。
- **背景素材**：`public/demo/backdrops/` 24 幅 2:1 原创 SVG，由封面生成脚本输出：原场景居中放大 1.4 倍，两侧为模糊镜像并以渐隐蒙版衔接；竖版封面从不拉伸。缺背景时：有封面则用封面 56px 高斯模糊作低透明氛围色，并叠加 Atlas 等高线；双缺图只用等高线与 token 渐变。图片失败各回退一次，不重试、不出现破图图标。
- **封面**：沿用 2:3 及 GameCover/占位组件，宽 `clamp(184px, 13cqi, 300px)`（低高度 168–240px，≤680px 容器 132px），首屏 eager 加载；DEMO 徽标恒显于标题上方。
- **关键数据**：累计游玩、最近游玩、成就（演示）、加入收藏四项细线分隔排成一行，不做卡片。`null` 游玩显示“暂无游玩数据”，0 显示“尚未开始”，无日期显示“暂无记录”，成就 `null` 显示“未提供”，绝不显示为 0%。
- **正文**：框架最大宽 2560px、两侧 40px（≤1440 容器 32px，≤1000 容器 24px，≤680 容器 16px）。>1400px 容器：简介（≤68ch）｜类型标签·成就·收藏档案（细线分隔，单块 ≤640px）｜我的记录面板（`clamp(320px,24cqi,420px)`，sticky）。≥2400px：简介 72ch、事实列内 auto-fit 多栏、面板 440px，间距 80px。≤1400px：事实区移到简介下方成 auto-fit 行；≤1000px：全部单列、面板不再 sticky。中文正文 15/1.85（4K 16），约 37 字/行。
- **我的记录**（唯一抬升面板）：状态四段单选、1–5 整星评分（radio，可清除；null=未评分）、备注（≤1000 字，Ctrl+Enter 保存，未修改时 Esc 取消）。每项独立显示“正在保存/已保存到本机演示存储/失败原因”，aria-live 宣告；保存期间显示目标值，失败回退为已存值，备注失败保留草稿。
- **未实现操作**：“启动游戏”禁用并在旁边以文字说明“暂不可用 · 演示模式未接入 Steam”。
- **高 DPI**：页面所有图像为 SVG，无需 srcset；细线、图标、文字在 DPR 1/1.5/2 截图中复核。真实位图接入后须提供 `srcset/sizes`。
- **动效与焦点**：沿用全局减少动画规则；进入详情焦点移到标题（无焦点框），返回 Library 焦点回到所开游戏；标题文档名同步。

## 11. 多平台作品库（2026-10-30）
- 用词：作品库 / 部作品 / 作品详情；状态“进行中”替代“在玩”；本机状态按类型显示“已安装/已下载”。
- 作品库标签栏改为作品类型：全部 / 游戏 / 图像 / 视频 / 音声 / 其他，Lucide 图标 + 数量，选中沿用下划线样式；切换类型时清空玩法分类，分类下拉只列当前类型的分类。工具栏新增“平台”下拉与“仅收藏”切换（与下拉同高 40px，选中为 accent 10% 底色），原“已安装/我的收藏”标签由“本机状态”下拉与“仅收藏”承担。
- 卡片与列表第二行：Steam 游戏显示累计游玩；其他平台或类型显示“类型 · 平台”（如“音声 · DLsite”）。
- 详情：眉题加入平台徽标与“类型 · 分类”；主操作按类型为 启动游戏 / 浏览作品 / 播放作品 / 打开文件夹（演示中禁用并注明未接入的平台）。Steam 关键数据为 累计游玩·最近游玩·成就·加入收藏；DLsite 为 作品类型·最近{阅读/观看/收听/游玩/打开}·发售日·加入收藏（检查点 4 起，与首页“最近体验”同一使用记录；制作方在收藏档案中），并省略成就区。收藏档案增加平台、制作方、发售日。
- 程序化封面调色按 `index + floor(index/18)` 取色，避免同类型作品配色重复。

## 12. 检查点 3：首页 Dashboard（2026-10-30）
- **层级**：全宽主视觉（精选作品背景+封面+标题+查看详情/换一个）→ 同屏 4 项关键数据（细线分隔，非卡片）→ 最近体验封面行 + “今晚玩什么”面板（唯一抬升面板）→ 细线分隔的洞察网格（最常玩、游玩时长分布、游戏类型、作品构成、待玩清单、来源与同步）。主视觉高度 `clamp(460px, 60vh, 780px)`，低高度 420px；1080P 首屏包含精选与 4 项数据。
- **范围切换**：全部作品 / 全部游戏 / Steam 游戏 / DLsite 游戏 / DLsite 其他作品，半透明分段控件位于主视觉右上，写入 `?scope=`。非游戏范围隐藏游戏专属模块（最常玩、时长分布、游戏类型），关键数据改为 作品总数·有体验记录·待体验·已下载，推荐标题改为“今晚看点、听点什么”。
- **统计口径**：已游玩=时长>0 的游戏；未开始=用户标记的状态；累计游玩只汇总有记录的游戏并显示覆盖数，无记录单列；DLsite 游戏显示“未提供”。游戏类型每款一个主类型、互斥。最近体验只按使用记录排序，购买/加入日期不计入。推荐从未开始/搁置的作品中按“本机可用、收藏、固定种子”挑选，同一批次稳定，点“换一批”才变化。
- **图表**：Recharts（按需懒加载），柱宽 ≤48px、圆角 4px、Steam=accent、DLsite=success；轴文字 11px muted；每图附标题、单位/口径说明与读屏文本列表，SVG 本身 aria-hidden。动画随减少动画关闭。
- **来源徽标**：Steam 用 accent、DLsite 用 success 的 32px 圆角字母块；连接状态徽章：已连接 success、连接中 accent、过期 warning、失败 danger、未连接 muted，均带文字。
- **演示任务**：顶栏下载图标显示进行中数量；弹层列出任务步骤（下载→校验→解压，无需解压时标“无需解压”）、确定进度条或无百分比的不定进度条、大小（未知显示“大小未知”）、取消/重试，并持续注明“仅演示，未写入任何文件”。详情页仅在作品具备下载能力时显示“演示下载并解压”；仅限官方阅读器的作品显示说明而非按钮；Steam 不显示下载入口。
- **响应式**：容器 ≤1100px 时推荐面板移到最近体验下方、关键数据两列；≥2400px 洞察网格自动增至 6 列，最近体验显示更多封面（按测量宽度只渲染完整卡片，不渲染隐藏但可聚焦的项）。

## 13. Phase 1 最终布局规则（检查点 4，2026-10-30）
以下为三个核心页面在验收中确认的边界，取代前文中与之冲突的早期描述。
- **布局依据**：一律按 CSS 视口与实际容器宽度（ResizeObserver / 容器查询 `cqi`）排版，不按物理像素。侧栏 232px，收起 72px；视口 ≤1280px 自动收起且不可手动展开（图标保留 `aria-label`），更宽时可手动收起/展开，收起后作品库重新测量列数并保留可见锚点。
- **作品库**：卡片宽 176–240px、列间距 20px、封面 2:3；实测列数 1080P 7–8、2K 9–11、4K 14–16、1280/1440 宽 4–6。卡片标题两行截断、高度一致；列表单行省略，完整标题可访问。列表名称列 260–1100px、其余列定宽并靠左排列，宽屏下类型/状态/时长紧随名称，不被推到行尾。
- **首页**：主视觉 `clamp(460px, 60vh, 780px)`；1920×1080 首屏同时可见精选与 4 项关键数据（1280×720 首屏可见精选，数据紧随其下）。洞察网格每列 ≥300px，最多 6 列并占满整行（`minmax(max(300px, (100% − 5×48px)/6), 1fr)`），不留空列；≥2400px 主区为 6 列。区块标题不换行，空间不足时操作按钮换到下一行。
- **图表**：横轴刻度只写数值（`<1 / 1–10 / 10–50 / 50–100 / 100+`），单位写在模块说明中，刻度之间留 ≥2px 间隔；悬停提示与读屏文本保留完整标签。范围切换期间，上一范围数据以 55% 不透明度显示并设 `aria-busy`，新范围到位后恢复，不把旧数字当作新范围展示。
- **详情**：标题按长度分三档 clamp（34–60 / 28–46 / 24–38px），`overflow-wrap:anywhere` 处理无空格长串；正文行宽 ≤900px。DLsite 关键数据为 作品类型·最近{阅读/观看/收听/游玩/打开}·发售日·加入收藏，与首页“最近体验”使用同一使用记录。
- **字号上限**：所有标题使用带上下限的 clamp（首页精选标题 ≤52px），不随 vw 无限放大；4K 通过增加列数和留白利用空间，而不是放大文字。
- **演示任务步骤**：步骤链使用名词（下载 / 校验 / 解压 / 无需解压），状态文案使用进行时（下载中 34%、已取消），避免已取消任务读起来仍在运行。
- **高 DPI**：封面、背景、图标与图表均为 SVG/矢量，DPR 1 / 1.5 / 2 下无需 `srcset`；接入真实位图封面时必须提供 `srcset/sizes`。拉丁字符用系统 Segoe UI，中文用本地打包的 Noto Sans SC；“A”头像与缺图占位中的单字使用 Georgia（Windows 系统字体，非网络加载）。
- **验证边界**：七档 Playwright 视口/DPR 是 Windows 缩放的近似，不等同于真实 125%/150%/200% 系统缩放；需在真实设备上人工确认。

## 14. 资料空间与服务状态（Phase 2 检查点 1）
- **模式标识**：顶栏右侧常驻，所有窗口宽度可见，点击打开设置。DEMO · 演示模式、测试库 · 合成数据 用警示色；我的资料库 用次要文字色；本地服务未连接 用危险色，侧栏状态点同步变色。
- **切换**：设置弹层顶部两张并列卡片（我的资料库 / 演示空间），当前项用主色描边和对勾。切换时若在作品详情页，回到作品库。
- **真实模式文案**：不出现“演示”“DEMO”“合成”。测试库所有页面标明“测试数据 · 合成样本”，不能显示成同步结果。
- **三种状态互不混淆**：加载用骨架；真实空库用“你的作品库还是空的”并引导查看来源状态；服务或读取失败用错误状态和重试。空库不提供“浏览演示收藏”。
- **未知值**：本机状态未知显示“本机状态未知”，不显示“未安装”；缺制作方显示“未提供”；缺类型显示“未分类”。
- **未加载的列表项**：网格用骨架卡片，列表用骨架行，尺寸与真实项相同，滚动不跳动。
- **未开放功能**：连接、同步、下载、打开在真实模式只说明后续开放，不提供假按钮；演示流程不会在真实作品上运行。
- **文件与版本**：详情页档案区下方列出每个文件；未知大小显示“大小未知”，不显示 0。

## 15. DLsite 连接面板（Phase 2 检查点 2）
- **位置**：来源连接弹层的 DLsite 卡片内。用户要求不能有在网页上登录的感觉，所以正常路径没有任何网页、窗口或跳转提示。
- **表单**：账号、密码、“记住账号和密码”（默认不勾选），主按钮“登录”，次按钮“改用网页登录”。下方一句话随勾选说明是否保存。不弹风险提示。
- **已保存账号**：显示打码账号和“登录”，一键登录；另有“使用其他账号”和“忘记保存的密码”。
- **进度**：转圈 + “正在登录 DLsite…” + 取消。徽标显示“连接中”。
- **需要验证**：说明这一步只能本人完成、完成后自动回来，提供“回到验证窗口”和取消。窗口用深色背景和 Library Atlas 标题。页面持续要求验证 6 秒以上才显示，避免跳转页造成闪窗。
- **已连接**：最近验证日期、“作品同步将在后续版本开放”、重新验证、断开，并说明断开不影响作品。不把连接时间写成同步时间。
- **失败**：警示色一句话说明原因，表单保留账号、清空密码。暂时无法验证与需要重新登录明确区分，前者不要求输入密码。
- **顶部账号入口**（用户反馈，参考 Steam）：顶栏右侧常驻，显示来源头像、状态点、打码账号和下拉箭头；未登录时显示“登录 DLsite”。菜单含状态、最近验证、重新验证、退出登录、设置。Esc 和点击外部关闭。
- **设置页**：左下角进入，居左单栏最宽 900px，分账号、文件夹、资料空间。文件夹一行：路径输入框、更改、打开；未设置时打开不可用；内容变动时“更改”变为“保存”。
- **矮屏**：高度不足 800px 时隐藏卡片的统计行，让登录按钮留在首屏内。

## 16. 作品同步与滚动（Phase 2 检查点 3）
- **同步面板**：在 DLsite 已连接状态下方。主按钮“同步作品库”，完成后变“重新同步”。进度有总数时显示数字和进度条，没有时显示不定进度，不编百分比。说明文字写明只读资料、不下载、范围是 DLsite Play。
- **结果**：完成用成功色，列出总数、新增、更新和未返回数；失败和部分完成用警示色，说明已保存多少。
- **作品库滚动**：向下滚动超过 24px 且列表足够长时，收起介绍、工具栏、页脚和顶栏，作品占满屏幕；向上滚动 40px 恢复；回到顶部恢复。短列表不收起。切换后 280ms 内不再次切换，避免抖动。收起时显示“回到顶部”。Ctrl+K 从收起状态直接聚焦搜索。减少动画模式下无过渡。
- **筛选中的数字**：新结果到达前保留上一次的数字，不闪 0。
- **列表栏目**：购买日期、作品名称、制作方、作品形式、进度、我的评价、发售日、大小、收藏。栏目名是按钮，点击排序，再点反向，当前排序显示方向箭头；未知值显示 — 并排在最后。窄屏按优先级隐藏次要栏目。没有的数据不补，不显示“已下载”。

## 17. 下载（Phase 2 检查点 4）
- **入口**：详情页的下载行。单个文件且文件夹已设置时，点一下直接开始。只有分卷要选或文件夹有问题时才弹窗。
- **进度**：显示真实字节。总大小未知时用不定进度条并写“总大小未知”，不显示 0 或百分比。没有可靠样本，不显示速度和剩余时间。
- **任务面板**：右上角下载图标，徽标是进行中的数量。每个文件一行，分卷写“第 N/M 个文件”。操作只显示当前可用的：暂停、继续（只在能续传时）、重新下载、取消、打开文件夹。
- **用词**：完成写“已下载”，并说明解压在后续版本。绝不写“已安装”“可玩”。真实模式不出现“演示”。
- **错误**：说明发生了什么和能做什么，不暴露地址和路径。文件名只显示名称，完整位置在悬停提示里。
- 下载出错不影响浏览作品库；进度刷新只更新任务，不让列表回到顶部，不打断正在写的备注。
