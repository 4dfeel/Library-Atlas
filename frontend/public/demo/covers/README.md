# Original Demo Cover Illustrations

These 24 cover illustrations were authored for Library Atlas as deterministic SVG
source art. They contain original fictional scenes, not screenshots, photographs,
logos, characters, or promotional artwork taken from existing games. Every file is
self-contained: no scripts, external images, web fonts, tracking, or network links.

Each composition has a 480 × 720 viewBox (2:3), scalable to any device pixel ratio.
These are normal cover assets, distinct from the UI's missing-cover placeholder.
The quiet palettes and simplified vector forms are deliberate illustrated-poster
art direction. They are not represented as painted or photographic game key art.

Rebuild from the repository root with:

```powershell
node scripts/generate-demo-covers.mjs
```

The generator contains individually authored scene compositions and small shared
vector drawing helpers. It has no dependencies and uses no random input.
